# ⚡ VOLT PREMIUM: Стан Проєкту та Пам'ятка

Цей файл створено для того, щоб ШІ-асистент (Antigravity) завжди знав поточний контекст проєкту, навіть після непередбачуваних збоїв чи перезапусків.

## 🛠 Технологічний Стек
- **Фронтенд:** Next.js 15 (App Router), React 19, Tailwind CSS v4, Framer Motion
- **Бекенд:** Next.js API Routes, NextAuth.js
- **База даних:** PostgreSQL (через Prisma ORM `v6.0.0`)
- **Деплой:** Docker + Coolify (на сервері `energy.texno.plus`)

## 📦 Останні глобальні зміни (Станом на 26 Травня)
1. **База даних:** Переведено з локального `sqlite` на серверний `postgresql`. В `schema.prisma` встановлено `provider = "postgresql"`.
2. **Адмінка (`/admin/settings`):** Створено єдину панель глобальних налаштувань (Логотип, Контакти, Соцмережі, Картки Прайсу, Текст та SEO для сторінки "Про нас").
3. **Rich Text (Візуальний редактор):** Інтегровано `react-quill-new` для сторінок Послуг, Портфоліо та "Про нас". Всі дані зберігаються як HTML (`aboutHtmlContent`, `pricingSeoText` тощо).
4. **SEO:** Повністю налаштовано динамічну серверну генерацію мета-тегів (Title, Description, OpenGraph) для Головної сторінки (`layout.tsx`), Прайсу (`pricing/layout.tsx`), Блогу (`blog/layout.tsx`), Портфоліо та Послуг. Всі теги тягнуться з бази даних `PageContent`.
5. **Дизайн:**
   - Карусель популярних послуг (Bento Grid) на головній сторінці.
   - Оновлені картки переваг на сторінці Прайсу.
   - Приховані ціни з калькулятора на публічній сторінці прайс-листа.

## ⚠️ Важливі нюанси локальної розробки
1. **Prisma та `.env`:** В `schema.prisma` вказано провайдер `postgresql`, але локально в `.env` (у розробника) змінна `DATABASE_URL` може вказувати на `sqlite` (`file:./dev.db`). Через це локальна команда `npx prisma db push` **не буде працювати** (помилка P1012). Це нормально, оскільки код підготовлено для сервера Coolify, де розгорнуто реальний Postgres.
2. **TypeScript:** Всі помилки типів у Next.js та Prisma Seed виправлені для успішного збирання (`npm run build`) у Docker на Coolify.
3. **Docker:** `Dockerfile` містить "заглушки" (dummy) для змінних середовища під час `npm run build`, щоб Next.js міг зібратися без реального підключення до бази. А скрипт `docker-entrypoint.sh` автоматично накочує базу та запускає сід (`npx prisma db push && npx prisma db seed`).
