# Інструкція з розгортання в Coolify

Ваш проєкт повністю підготовлений для автоматичного розгортання (Deploy) через **Coolify** з використанням Docker.

## Що вже налаштовано "з коробки":
1. **Dockerfile**: Оптимізований для Next.js (Standalone build), щоб споживати мінімум оперативної пам'яті сервера.
2. **SQLite Volume**: База даних автоматично зберігається на сервері, тому при оновленні сайту ви не втратите свої тексти і статті.
3. **Авто-Seed**: При кожному запуску Docker-контейнера запускається `docker-entrypoint.sh`. Якщо база даних порожня, він автоматично заповнить її всіма стартовими текстами (Послуги, FAQ, Процес роботи, Ціни тощо).

## Покрокова інструкція для Coolify:

1. **Завантажте код на GitHub або GitLab**.
2. Зайдіть у свою панель **Coolify**.
3. Натисніть **Add New Resource** -> **Application** -> **Public Repository** (або Private, якщо репозиторій закритий).
4. Виберіть ваш репозиторій і гілку (наприклад, `main`).
5. У налаштуваннях (Configuration) виберіть тип розгортання: **Docker Compose** або **Dockerfile**.
   - Рекомендую використовувати **Docker Compose**, оскільки він автоматично підтягне налаштування файлу `docker-compose.yml`, включно зі створенням тому (`volume`) для збереження бази даних.
6. **Змінні середовища (Environment Variables):**
   Обов'язково додайте в Coolify наступні змінні:
   - `NEXTAUTH_SECRET` = (придумайте будь-який довгий випадковий пароль, наприклад: `my_super_secret_volt_key_2024_xYz`)
   - `NEXTAUTH_URL` = (вставте адресу вашого сайту, наприклад: `https://voltpremium.ua`)
7. Натисніть **Deploy**.

Готово! Coolify сам збере проєкт, запустить контейнер, а контейнер сам створить і заповнить базу даних! 🚀
