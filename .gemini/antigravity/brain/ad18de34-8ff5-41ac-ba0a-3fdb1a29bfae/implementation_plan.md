# Оновлення Галереї та Адмін-панелі

Цей план описує архітектурні зміни та оновлення інтерфейсу для реалізації розширеної галереї (з відео, цінами та описом робіт) та забезпечення повного редагування всіх блоків з адмін-панелі.

## User Review Required

> [!WARNING]
> **Формат Відео:** Для відео, які завантажуються безпосередньо з ПК, автоматична конвертація/стиснення на стороні сервера (через `ffmpeg`) може бути ресурсомісткою для звичайного хостингу (наприклад, Vercel). Чи погоджуєтесь ви використовувати або **прямі посилання (YouTube/Vimeo)**, або **пряме завантаження MP4 файлів** без автоматичного переформатування на сервері? (Ми встановимо ліміт розміру файлу, наприклад, 50MB).

## Open Questions

1. Блок "Як ми працюємо" — чи потрібно створити окремий розділ/таблицю в базі даних для кроків (наприклад: 1. Дзвінок, 2. Проект, 3. Монтаж), чи достатньо додати текстові поля в загальні налаштування сторінки?
2. Чи потрібно додати окрему сторінку "Портфоліо" (`/portfolio`), де будуть виводитись усі роботи у вигляді великої сітки з фільтрами, чи вистачить каруселі на головній?

## Proposed Changes

---

### Database Schema

#### [MODIFY] `prisma/schema.prisma`
- Оновлення моделі `GalleryImage`:
  - Додати поле `price String?`
  - Додати поле `whatWasDone String?`
  - Додати поле `type String @default("IMAGE")` (значення: IMAGE або VIDEO)
- Створення/оновлення бази для бази "Як ми працюємо" (якщо буде окрема таблиця `WorkStep`).

---

- Оновити обробку POST/PATCH запитів для прийняття нових полів (`price`, `whatWasDone`, `type`).

- Це дозволить вам створювати та редагувати структурні статті, таблиці з цінами, списки виробників та блоки прямо з адмінки без знання коду.

## Verification Plan

### Manual Verification
1. Зайти в адмін-панель -> Галерея. Спробувати завантажити фото з ПК, заповнити ціну та опис робіт.
2. Спробувати завантажити відео (або вставити посилання на YouTube).
3. Перевірити головну сторінку: чи відображаються нові фото/відео з текстами поверх них.
4. Перевірити, чи зберігаються зміни SVG та текстів для блоків "Стандарти" та "FAQ".
